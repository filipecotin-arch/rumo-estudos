# JG+ Estúdio — demonstração pública

Demonstração independente e sem dados reais, dedicada a testar visualmente a gestão de projetos de arquitetura.

O sistema completo permanece no repositório privado `jg-arquitetos-gestao`.

Esta demonstração não contém login real, contratos, dados de clientes ou integração com Google Calendar. Tudo que for editado fica somente no navegador do visitante.
